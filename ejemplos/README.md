# Ejemplos

Proyectos completos que acompañan los capítulos del curso. Cada carpeta se puede abrir sola: no necesitas instalar nada.

| Carpeta | Capítulo | Qué demuestra |
|---|---|---|
| `mi-tarjeta/` | 02 — Tu primera web | HTML, CSS y JavaScript con modo oscuro y diseño mobile first |

## Cómo usarlos

1. Descarga el repositorio o clónalo:
   ```bash
   git clone https://github.com/EverKrypton/tutorial-dev.git
   ```
2. Abre `index.html` en el navegador.
3. Cambia el texto, los colores y el nombre. Rompe cosas. Vuelve a empezar.

## Para publicarlo

Copia la carpeta a un repositorio propio y conéctalo a Vercel. O desde esta carpeta:

```bash
cd ejemplos/mi-tarjeta
vercel --prod
```

Más detalles en el capítulo 04 del curso.
