Linux en el bolsillo

Termux es una app de Android que te da una terminal Linux de verdad, sin root y sin emulador. Dentro tienes bash, git, node, python, openssh y un gestor de paquetes propio. No es una maqueta: es un entorno real con el que puedes programar y hasta servir una web.

Sirve para tres cosas concretas:

  • Practicar todo lo del capítulo anterior sin encender la computadora.
  • Tener Git, Node y Python en el teléfono, para arreglar algo desde cualquier sitio.
  • Entender Linux de verdad, porque aquí no hay interfaz gráfica que tape lo que pasa.
En simple

Tu teléfono ya es una computadora. Termux es la puerta para usar esa computadora como se usaba antes: escribiendo órdenes.

Instalar Termux (por F-Droid)

Esto importa: la versión de Google Play está abandonada y da errores raros con los paquetes. La versión que funciona es la de F-Droid.

  1. Instala F-Droid

    Abre f-droid.org en el navegador del teléfono y descarga el APK. Android te pedirá permiso para instalar apps de esta fuente: acéptalo solo para F-Droid.

  2. Busca Termux dentro de F-Droid

    Enlace directo: f-droid.org/packages/com.termux. Pulsa «Descargar APK» o instálalo desde la app de F-Droid.

  3. Instala y abre

    Verás un prompt como ~ $. Ya estás dentro de un Linux.

  4. Actualiza todo antes de nada

    bash
    pkg update
pkg upgrade -y

    La primera vez tarda un rato y pregunta cosas: acepta los valores por defecto pulsando Enter.

No mezcles repositorios

Si instalas Termux desde Play Store y luego desde F-Droid, las firmas no coinciden y Android no te deja actualizar. Desinstala la de Play Store antes. Y no instales la versión de Play Store «porque es más fácil»: es la causa del 90% de los errores de paquetes.

Permisos que conviene darle

bash
termux-setup-storage     # acceso a Descargas, Documentos, etc.
termux-wake-lock         # evita que Android duerma la sesión
termux-wake-unlock       # liberarlo cuando termines

Después de termux-setup-storage tendrás una carpeta ~/storage con enlaces a lo que hay en el teléfono:

bash
ls ~/storage
# dcim  downloads  movies  music  pictures  shared

cd ~/storage/downloads
ls

pkg, apt y la diferencia que confunde

En Termux el gestor de paquetes se llama pkg. Es un envoltorio cómodo sobre apt, que también existe dentro de Termux. Los dos funcionan, pero pkg hace lo correcto por defecto.

Por qué en Termux no hay sudo

Termux corre como un usuario normal dentro de Android. No hay sudo porque no eres root del sistema y no lo necesitas: tus paquetes van a $PREFIX, una carpeta tuya. Si de verdad necesitas apt con root simulado, se hace con proot-distro (lo vemos abajo).

Instalar lo esencial, paso a paso

Este es el bloque que vas a ejecutar el primer día. Cópialo tal cual, en orden.

bash
# 1. Actualizar el sistema de paquetes
pkg update -y && pkg upgrade -y

# 2. Herramientas base
pkg install -y git nano curl wget unzip tar

# 3. Node.js y npm
pkg install -y nodejs-lts

# 4. Python
pkg install -y python

# 5. OpenSSL (el binario y las cabeceras)
pkg install -y openssl openssl-tool

# 6. SSH: cliente y servidor
pkg install -y openssh

# 7. Comprobar que todo está
git --version
node -v
npm -v
python --version
openssl version
ssh -V

Si un paquete falla

Ejecuta pkg update otra vez y repite. Si sigue, mira el mensaje completo: casi siempre dice «dependencia X no encontrada», y se resuelve instalando esa dependencia primero. No borres la app: perderías todo lo que tengas en ~.

Certificados y certbot

Certbot sirve para pedir certificados HTTPS gratuitos de Let's Encrypt. En Termux solo tiene sentido si estás sirviendo algo con un dominio real; en el teléfono, para practicar, casi nunca lo necesitas.

Intenta primero el paquete nativo:

bash
pkg install -y certbot

Si no existe en tu repositorio, instálalo con pip dentro de Python:

bash
pkg install -y python-pip
pip install --upgrade certbot

# comprobar
certbot --version

Uso típico en un servidor de verdad (VPS, no teléfono):

bash
# 1. El dominio tiene que apuntar ya a tu IP
dig +short midominio.com

# 2. Pedir el certificado con nginx delante
sudo certbot --nginx -d midominio.com -d www.midominio.com

# 3. Probar la renovación automática
sudo certbot renew --dry-run

# 4. Ver los certificados
sudo certbot certificates
Si no tienes dominio

Let's Encrypt no emite certificados para direcciones IP ni para localhost. Para practicar HTTPS en local, genera un certificado autofirmado con openssl (lo tienes más abajo) y acepta el aviso del navegador.

Un certificado autofirmado con openssl

bash
# clave privada + certificado válido 365 días
openssl req -x509 -newkey rsa:2048 -nodes \
  -keyout key.pem -out cert.pem -days 365 \
  -subj "/CN=localhost"

# ver qué contiene
openssl x509 -in cert.pem -noout -text | head -20

# generar un secreto aleatorio (útil para JWT, sesiones)
openssl rand -hex 32

apt de verdad con proot-distro

Si quieres un Debian o Ubuntu completo dentro del teléfono, con apt, sudo y todo:

bash
pkg install -y proot-distro

# instalar una distro
proot-distro install debian

# entrar
proot-distro login debian

# ya dentro, esto sí es apt de verdad
apt update
apt upgrade -y
apt install -y curl git nano python3 nodejs openssl certbot

# salir
exit
No mezcles los dos mundos

Lo que instalas con pkg vive fuera de la distro y lo que instalas con apt vive dentro. Un node instalado con pkg no aparece al entrar en Debian. Decide dónde vas a trabajar y quédate ahí.

Git en Termux: los ajustes que sí importan

bash
# identidad (una sola vez)
git config --global user.name "Tu Nombre"
git config --global user.email "tu@correo.com"

# nano como editor: sin esto, git abre vi y te pierdes
git config --global core.editor nano

# rama principal moderna
git config --global init.defaultBranch main

# que no pida usuario y contraseña en cada push
git config --global credential.helper store

# claves SSH (mejor que contraseñas)
ssh-keygen -t ed25519 -C "tu@correo.com"
cat ~/.ssh/id_ed25519.pub
# copia esa línea y pégala en GitHub → Settings → SSH keys

# probar la conexión
ssh -T git@github.com
El token, no la contraseña

GitHub ya no acepta contraseñas por HTTPS. Si usas credential.helper store, cuando pida contraseña pega un token personal (Settings → Developer settings → Tokens). Y ojo: store guarda el token en texto plano en ~/.git-credentials. En un teléfono compartido, usa SSH.

Servir algo desde el teléfono

No es lo normal, pero se puede y enseña mucho:

bash
# un servidor estático en el puerto 8080
cd ~/storage/downloads/mi-web
python -m http.server 8080

# en el navegador del teléfono:
# http://localhost:8080

Para que no se corte al bloquear la pantalla:

bash
termux-wake-lock
nohup python -m http.server 8080 > ~/server.log 2>&1 &

# ver el log
tail -f ~/server.log

# pararlo
pkill -f http.server
Termux no es un servidor de producción

Android duerme procesos, la IP cambia y no hay garantía de disponibilidad. Úsalo para probar y aprender. Cuando algo tiene que estar encendido de verdad, va a un VPS o a Vercel.

Ejercicios

Ejercicio 01

Poner el taller en marcha

Instala Termux desde F-Droid, ejecuta pkg update && pkg upgrade -y, instala git nano nodejs-lts python openssl openssh y comprueba las seis versiones. Si algo falla, lee el error completo antes de tocar nada.

Ejercicio 02

Tu primer repositorio en el teléfono

Crea ~/proyectos/prueba, un README.md con nano, y haz git init, git add ., git commit -m "inicio". Después mira el historial con git log --oneline y el estado con git status.

Ejercicio 03

Rama, conflicto y deshacer

Crea una rama, cambia la misma línea del README en dos ramas distintas y provoca un conflicto al mezclar. Resuélvelo a mano en nano, haz commit, y luego practica git restore y git stash.

Ejercicio 04

Servir tu web desde el bolsillo

Copia una carpeta con un index.html a ~/storage/downloads, sirve con python -m http.server y ábrela en el navegador del teléfono. Después hazlo con nohup y termux-wake-lock y comprueba que sigue viva al cambiar de app.

Lo importante

Termux no es un juguete: es un Linux completo que cabe en el bolsillo. Todo lo que aprendas aquí se aplica tal cual en un VPS. La diferencia entre los dos es solo dónde está enchufado el cable.
