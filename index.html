v0 Prompting

Al terminar.

Sin promesas de gurú. Cosas concretas que puedes demostrar con una URL y un repositorio.

  • Explicar qué pasa desde que escribes una dirección hasta que ves la página.
  • Escribir HTML y CSS ordenado, accesible y que se vea bien en un teléfono.
  • Usar Git para guardar, comparar y deshacer cambios sin entrar en pánico.
  • Publicar en Vercel, conectar un dominio y entender los deploys de preview.
  • Pedirle a v0 una interfaz y convertirla en algo propio, no en una plantilla ajena.
  • Trabajar con una IA en la terminal, cambiar de modelo y controlar sus permisos.
  • Escribir una skill y un agente para repetir tu forma de trabajar.
  • Diseñar prompts con contexto, estructura, ejemplos y criterios de evaluación.

Cómo está hecho este sitio.

Si vas a aprender a construir para la web, tiene sentido que puedas mirar debajo de la que estás leyendo.

01

HTML y CSS a mano.

Sin frameworks, sin generador, sin build. Un archivo de JavaScript para el tema, el progreso y los atajos. Nada más.

02

Mobile first de verdad.

Los estilos base son para 360 px. Lo que viene después son mejoras para pantallas más grandes, no parches.

03

Abierto.

El código está en GitHub con licencia MIT. Si una explicación no se entiende, se puede corregir.

04

Deploy automático.

Cada push a la rama principal publica una versión nueva en Vercel. Lo mismo que vas a hacer tú en el capítulo 04.
