El temario está en orden, pero puedes empezar donde te corresponda. Estas son las tres entradas más comunes.

Nunca he programado

Quiero entender antes de tocar.

Empieza por los fundamentos y sigue en orden hasta publicar. Es el camino más lento y el que menos huecos deja.

Entregables 04

Cuatro cosas que vas a tener al terminar.

Al terminar tendrás artefactos que puedes abrir, enseñar y usar como base de lo siguiente.

01

Un sitio publicado

Con URL propia, HTTPS y deploy automático desde tu repositorio.

02

Un repositorio ordenado

Con historial legible, ramas y un README que explica cómo correrlo.

03

Un entorno de IA

opencode configurado, con una skill y tres agentes que trabajan a tu manera.

04

Un método de prompting

Plantillas, criterios de evaluación y la costumbre de verificar lo que la IA afirma.

Colofón 05

Cómo está hecho este sitio.

Si vas a aprender a construir para la web, tiene sentido que puedas mirar debajo de la que estás leyendo.

01

HTML y CSS a mano.

Sin frameworks, sin generador, sin build. Un archivo de JavaScript para el tema, el progreso y los atajos.

02

Mobile first.

Los estilos base son para 360 px. Lo que viene después son mejoras para pantallas grandes, no parches.

03

Abierto.

El código está en GitHub con licencia MIT. Si una explicación no se entiende, se puede corregir.

04

Deploy automático.

Cada push a la rama principal publica una versión nueva en Vercel. Lo mismo que harás en el capítulo 04.

Empieza por el capítulo 01.

No hace falta instalar nada: veinte minutos y un navegador alcanzan para entender cómo funciona la máquina.
